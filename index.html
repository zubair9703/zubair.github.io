Find the pond, measure what is happening inside it, and warn the farmer before it goes wrong. Each project is a stage of the same problem.

Detection · production pipeline

Aqua-Boundary

A distributed geospatial ML pipeline that finds aquaculture ponds in satellite imagery and emits production-ready GeoJSON. YOLOv8 proposes pond regions, SAM ViT-H refines them into masks, and the masks are vectorised — orchestrated as separate Temporal activities so each model stage scales on its own.

Stack  YOLOv8 · SAM ViT-H · Temporal · FastAPI · Docker · S3 Region  4 districts, Andhra Pradesh Result  94% mIoU · 3 tiles in 2 minutes

Research · spectral index

Shrimp Index (SI)

Remote sensing had no index for shrimp farming, so I derived one. Multi-temporal and mono-temporal spectral analysis across farms showed a red-edge peak driven by phytoplankton and a strong NIR response from feed and biomass — a signature no other water body shares.

Method  Pond-level spectral analysis · Sentinel-2 L2A Index  SI = (RE3 − SWIR) / (RE3 + SWIR) Signal  Rising trend = healthy · falling = distressed

Decision system · early warning

SIRAS / EWIS

Farmers usually catch disease and water-quality problems only once they are severe. This system watches the rate of change in each pond's spectral signature over time, classifies pond state, and cross-checks sampled average body weight against the standard growth curve to raise an alert while there is still time to act.

Method  Temporal spectral trends + in-situ ABW · rule-based Output  PCS / PHS scores, combined alert label, DOC Result  80% overall accuracy across regions
